# PortaSplit 案例如何转化为 Creative Review

来源：Codex 项目任务 `019f68b1-ed4e-71a0-bb2d-2ed537f33b14` 的真实制作迭代记录。

这不是为 Demo 临时编写的评语，而是从实际广告创意与 AIGC 制作协作中提炼出的判断方法。

## 1. 三步卖点不能被拍成九步教程

项目卖点是 `3-step self-install`。早期九宫格为了保持连续性，把靠近、抓握、提起、跨门、落地、理管等过程拆得过细，导致产品看起来更难安装。

Review Card 的判断不是“动作不够顺”，而是：

- Issue：三步安装被拆成连续教学过程；
- Impact：`Simple setup` 的商业信息被制作过程稀释；
- Evidence：Storyboard V2 的重复搬运与理管镜头；
- Suggestion：使用三个不同景别的广告切镜，每个镜头只传递一个信息点。

## 2. 尾帧先是广告画面，其次才是安装说明

九宫格自动生成的尾帧曾把室内机做得过大、过近，雕塑退成背景元素。产品结构虽然更明显，但创意主角和高级家居氛围丢失。

判断原则：

- 雕塑是叙事主角；
- PortaSplit 是自然解决问题的产品角色；
- 外机和冷媒管需要可理解，但不能抢走画面主次；
- 先锁定 Hero Shot，再反推安装过程的终点状态。

## 3. AIGC 连续性错误会直接伤害产品可信度

真实迭代中出现过：外机凭空出现、内外机互换、产品尺寸漂移、冷媒管悬浮，以及人物搬起整台室内机等问题。

这类问题不能只标成“AI 瑕疵”，因为它们破坏的是消费者对三步安装的理解。系统需要同时记录：

- 视觉现象；
- 对产品传播的影响；
- 发生在哪个镜头/版本；
- 下一轮生成需要锁定的空间关系。

本案例的约束是：外机开场位于室内机后方并被遮挡；开门后先露出提手或少量格栅；随后短距离移至阳台；室内机全程不动。

## 4. Reference 不是照抄对象

制作需求交接时，半成品分镜、KOC 抽帧和官方产品图承担不同角色：

- 半成品分镜：参考动作、景别与构图；
- KOC 抽帧：参考安装顺序和真实动作；
- 官方产品图：约束产品结构、比例和运行状态；
- 文字 Brief：决定最终商业目标与不可修改项。

这正是 AdFrame 需要管理的“评测上下文”：同一条判断必须知道目标、证据来源、修改影响和保持不变的内容。
