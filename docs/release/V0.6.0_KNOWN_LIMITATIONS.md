# v0.6.0 已知边界

## 不是缺陷

- 没有任意 Resize Handle：已用紧凑 / 标准 / 展开密度模式替代；
- Current Artifact 位于工作区域：Pending Return Zone 只放待确认结果；
- Context、Command、Run 等内部对象并非都需要用户手动创建；
- Fixture URL 只用于 QA，不属于正式用户导航。
