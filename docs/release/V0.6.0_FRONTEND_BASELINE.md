# v0.6.0 前端基线交接

## 目标

在不接真实后端的前提下，冻结一条已验证的用户路径，让后续 Local Core、Bridge、Codex Runtime 和 Artifact Return 接口接入稳定的前端合同。

## 用户只需理解的模型

- Canvas：内容与关系；
- Work Rail：当前焦点、指令、任务和结果；
- Project / Scope：项目与空间层级。

内部的 ArtifactView、Context Snapshot、Run、Revision Binding 等概念不进入黄金路径。

## Work Rail 合同

- 始终只有一个实例；
- 根据 Workspace、选择、Run、Waiting Input、Review 自动变化；
- Composer 常驻，但绑定当前项目和选择，不是通用聊天框；
- Compare 临时扩宽同一个 Rail；
- 1366 或窄窗口可折叠为 Compact Rail；
- 当前项目保存 collapsed、width 和最近焦点。

## Task Loop 合同

```text
Selection
→ Composer
→ Run Confirmation
→ Command / Context Snapshot / Run
→ Running / Waiting Input
→ Artifact Return / Compare
→ Accept / Continue Modify
```

确认框打开时不得创建 Process；只有最终确认后 Process 数量增加 1。

## Scope 合同

- 一个项目一个 Project Graph；
- Child Canvas 是 Scope；
- 父 Canvas Artifact 不因删除 Child Scope 被删除；
- Child 只创建 ArtifactView 与内部关系副本；
- Workspace 保存 scopeId、camera、zoom、focusedNodeIds、visibleLayers、contextPolicy；
- 自动布局只移动当前 Scope 中未固定的 View。

## Alpha 接口优先级

1. Project Catalog / Project Session；
2. Artifact 与 ArtifactView；
3. Workspace 与 Canvas Scope；
4. Command / Context Snapshot / Run；
5. Run Event 与 Waiting Input；
6. Artifact Return / Revision / Accept；
7. Checkpoint；
8. 文件 Watcher、Connector 和 Delivery。
