## 实际范围

仅修复 Desktop Runtime 的构建、打包和启动链：

1. Electron 43 ESM 入口不再用顶层 `await app.whenReady()` 阻塞生命周期，改为 ready Promise 回调启动。
2. Runtime 准备脚本不再使用会在 Windows 压缩目录上触发 Node fast-fail 的递归 `cpSync`，改为显式遍历复制。
3. 为 Local Core 构建并打包运行时 `@local-creative-os/contracts`，避免 Desktop 中从工作区源码回溯解析。
4. Runtime 校验新增 Contracts 必需文件检查。
5. 使用项目本地 Python venv 构建内置 `lcos-bridge.exe`，未污染系统 Python。

## 流程变化

变更前：

```text
Electron 启动
→ 顶层 await app.whenReady() 停滞
→ 或 Runtime 复制 dist 时 Node 崩溃
→ 或 Local Core 找不到 contracts
→ Desktop 不可用
```

变更后：

```text
Electron 启动
→ app.whenReady().then(...)
→ 准备并校验完整 Runtime
→ 启动包内 lcos-bridge.exe（127.0.0.1:43122）
→ 启动 Local Core（127.0.0.1:43121）
→ 启动本地 Web Host 与 Desktop 窗口
```
