# LCOS 手测说明书（2026-08-08 基线）

> 这篇按“第一次打开的人照着点也能走通”来写。当前基线：Phase 4 前端合并 + B5/B6 历史接后端 + 提示词与首次单击脱钩。

## 0. 怎么打开

1. 确认三个服务在跑：Core 43121、Bridge 43122、Web 5173（浏览器地址栏输入 `http://127.0.0.1:5173`）。
2. 直接打开 `http://127.0.0.1:5173/?agent=codex&project=disposable-mvp-sample` 进入预置项目（LCOS MVP Sample，9 个节点 6 条线），这是最完整的体验样例。
3. 也可以不带参数打开 `http://127.0.0.1:5173` 进项目首页，从“继续一个项目”里选。

## 1. 界面长什么样

- 顶部：项目名（LCOS MVP Sample）+ 项目操作（搜索/导入/全局 Agent 对话/项目历史/更多）。
- 左侧：工作空间列表（Brief / Script、Reference / Feedback、Handoff Review）+ “新建工作空间”。
- 中间：画布，节点是卡片（图标 + 类型 + 版本数），节点之间有连线。
- 底部：导航 dock（主画布 / 当前现场 / 整理 / 上下文 / 运行 / 交付），其中“整理”里还能切“自由 / 大纲”两种投影。
- 右侧（Agent 模式）：本地 Agent 对话卡片，和画布实时联动。

## 2. 画布基本操作（先练这个）

### 选中
- 单击节点：只选中，不弹任何浮层（新版行为）。
- 再单击同一个已选中的节点：弹出提示词框（“对「X」做什么…”），输入内容后 Ctrl+Enter 发给 Agent。
- 按住 Ctrl 单击：加选 / 反选多个节点。
- 单击空白处：取消选择。
- Esc：逐级退出浮层/取消选择。

### 拖动与缩放
- 按住节点拖动：移动卡片（多选时整组一起动）。
- 节点右下角手柄：调整卡片大小（单选时出现）。
- 画布空白处按住左键拖动：框选；按住中键或空格+左键：平移画布；滚轮：缩放。

### 连线
- 鼠标悬停节点：左右出现连接锚点。按住右侧锚点拖到另一个节点：建立关系（连线）。
- 单击连线：出现编辑控件（两端重连圆点 + 中间剪刀）。
- 中间剪刀：删除这条关系；拖两端圆点：改接别的节点。
- 节点左上锚点：把某个节点设为当前节点的内容集合（Context）。

### 多选后的工具条
选中两个以上节点，选区上方出现工具条：
- Agent：把选中的内容交给 Agent。
- Collection：把选区创建为一个集合（Scope）。
- 投送：把选区投送到别的空间。
- 整理：自动排列选区（Ctrl/Cmd+Shift+L）。
- 更多：复制 / 额外 View / 删除 View。

### 投送（DropShelf）
- 选中一组节点后，按住其中任意一个拖到画布**底部或左侧边缘**，出现“投送”热区（高亮），松手。
- 弹出投送面板：目的地有“当前现场”、各工作空间、集合、“主画布”。点目的地放入，或点右侧箭头“放入并前往”。
- 投送面板在左下角（anchor-bottom）或左侧（anchor-left）弹出；点面板外或 Esc 取消。

## 3. 底部导航（六个入口）

### 主画布
项目根画布，所有节点在这里自由整理。

### 当前现场（Workbench）
一次工作批次的临时现场。把素材投送进来 → 整理 → 跑 Run → 结果确认后“并回”主画布，现场清空准备下一批。

### 整理（自由 / 大纲）
- 自由：就是主画布模式。
- 大纲：同一批节点变成树状大纲（按类型/版本/状态分组），适合快速看全貌。

### 上下文
流式时间轴 + 历史：
- 顶部：Agent 交接条（比如 Codex → WorkBuddy），显示项目里记录过的交接链。
- 轴区：按分类（需求/方案/执行等）分组的节点流。
- 右侧历史栏：项目的 Context 快照列表（每次快照冻结当时的节点/关系/备注/Run 引用）。
  - 点一条快照：看它的摘要（几个对象/关系/备注/Run）。
  - “对比当前”：对比该快照与最新快照，新增/移除/不变的数量会提示，并高亮变化对象。
  - “从这里建现场”：把快照里冻结的内容投送到当前现场，历史保持只读。
  - “来源”：定位到该快照对应的 Run 或节点。

### 运行
当前 Run 的工作台：显示运行中/等待输入/待审核的任务、事件流、取消/重试/审核按钮。

### 交付
审核产出：接受 / 拒绝 / 重试，对比修订版本，查看返回的产物。

## 4. 跑一个完整 Run（黄金路径）

1. 在画布单击选中一个节点（比如“Script”）。
2. **再单击它一次**，弹出提示词框。
3. 输入人话指令，例如“把开场压到三秒，保留产品卖点”，按 Ctrl+Enter。
4. 看节点状态变化：排队 → 运行中 → 等待输入（如需）→ 待审核。
5. 去“运行”或“交付”入口审核：接受（把结果并回）/ 拒绝 / 重试。
6. 接受后节点出现新版本（版本数 +1），右上角可切回历史版本。
7. 需要保留现场时：在“上下文”历史栏“从这里建现场”，把当时的上下文投进工作台。

## 5. 工作空间（左侧）

- 点工作空间名：进入该空间（画布上出现框体，只显示该空间成员）。
- “新建工作空间”：起名、选范围，建好后把节点拖进框体即加入。
- 框体标题栏：拖动框体（成员跟着动）；右下角手柄：调整框体大小；框体边缘小圆点：把整个框体连到别的节点。
- 返回总览：点“当前 Scope 总览”。

## 6. 导入文件

- 顶部“导入”按钮：选本地文件/目录，导入为画布节点（按 Windows 桌面图标风格显示类型）。
- 直接拖文件进画布：在落点创建节点。
- 项目首页“导入工程文件”：导入 `.lcosproj` 工程包。

## 7. 项目首页

- 继续一个项目：卡片列表，支持搜索、排序（最近更新/最近打开/名称）。
- 创建项目：空白项目 / 从文件夹创建（选择已有目录）。
- 删除项目：卡片上删除按钮，确认后移除（数据保留在本地，可恢复的删除为软删除）。

## 9. 已知提示

- 本地 Agent 显示“暂不可用”时，说明 Agent 桥接未连上，先确认 Bridge 43122 在跑、Codex 会话已接单。
- 快照历史在 seed 项目里有 4 条（含两条“Phase4 验收基线”），这是上轮验收数据，删不删都不影响功能。
- 画布布局偏好（投影位置等）存在浏览器 localStorage，清缓存会恢复默认布局，不影响项目数据。
- 运行中取消、SSE 秒级推送等高级项本轮已实现，但手测以 1–8 节为准。
