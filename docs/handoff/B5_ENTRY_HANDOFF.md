# B5 Entry Handoff

B4 hands B5 a stable understanding runtime. B5 must not redesign Intent/Attention.

## Available from B4
- WorkStateSnapshot
- explicit/correctable Intent
- Selected / Pinned / Related / Retrieved evidence with provenance
- progressive Context Pack
- Skill / Target proposal
- side-effect classification
- Continuity Candidate suppression
- multi-provider Utility intelligence

## B5 priority

1. Unified ChangeSet / Undo
2. Feedback → Decision → Change Request → Revision → Run → Version
3. direct Relation manipulation / metadata
4. Local Event Bus / same-user multi-surface synchronization
5. Proposal Ghost → Apply → ChangeSet

## Mandatory boundary

B4 can `Resolve / Rank / Preview / Prepare`.

B5 is where reliable `Mutate / Undo / Revert / Apply` begins.

Do not let an Agent proposal bypass ChangeSet because B4 rated its Intent confidence high.
