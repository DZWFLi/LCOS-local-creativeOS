# LCOS 第一次打开：给完全新手的傻瓜教程

> 版本：MVP（Gate F）· 2026-08-05
> 适用：完全不知道这个项目是什么、第一次打开它的人。

## 0. 先说人话：这到底是个啥？

Local Creative OS（LCOS）是一个装在你自己电脑上的「创意工作台」：

- 中间一大块空白叫**画布**，文件、文字、想法都可以做成一张张卡片（节点）摆上去；
- 右边一条栏叫**AI 工作栏**，用来看 AI 正在干什么、干完怎么处理；
- 选中卡片后弹出的输入框，就是**你对 AI 下命令的地方**；
- 所有东西都只存在你这台电脑上，不上传云端。

一句话：像「白板 + 文件夹 + AI 助手」三合一。

## 1. 怎么打开

在项目目录（`.worktrees/mvp-fast-build`）执行：

```powershell
npm run dev:open
```

它会自动做两件事：启动 3 个本地服务，再打开一个叫 **Local Creative OS** 的浏览器窗口。

- 想看服务是否正常：`npm run dev:status`（5173 / 43121 / 43122 三个端口都要 LISTEN）
- 想关掉：`npm run dev:stop`（或者直接关浏览器窗口）

打不开？直接看第 9 节「常见问题」。

## 2. 第一次看到的画面

- **左边一列**：工作空间栏（画布总览、几个工作空间，点来点去切换）
- **中间**：画布，上面摆着卡片（节点）
- **右边一条**：AI 工作栏（没任务时显示“对整个XX直接工作”）
- **进入时的列表**：项目选择页

## 3. 第一步：先开一个项目

1. 如果停在项目列表，点 **disposable-mvp-sample**（自带示例项目）；
2. 画布上会出现几张卡片，名字大概是 brief / script / reference / feedback；
3. 想建自己的项目也行，但新手建议先用示例项目把感觉找出来。

## 4. 认识卡片（节点）

- **单击** = 选中（选中后卡片下方会弹出输入框，这就是命令台）；
- **双击** = 打开这张卡片的内容（对象工作台）；
- **按住拖动** = 移动卡片；
- **Ctrl/Cmd + 单击** = 多选；在空白处拖框 = 框选；
- 卡片分几类：来源文件、工作稿、AI 生成草稿、参考、过程节点。

不用背，看图标、边框和文字就能分出来。

## 5. 第二步：往画布里放东西

新手三选一：

- 双击示例项目里已有的文字卡片，先看看内容长什么样；
- 拖一个本地文件进画布，它会变成一张新卡片；
- 新建一张文字卡片，随便写两句话（找「新建/创建」入口）。

## 6. 第三步：让 AI 干活（核心体验）

1. **单击一张卡片**选中它（比如 script）；
2. 在下方输入框写人话，比如：*“帮我给这段脚本加一句结尾”*；
3. 选 Agent：下拉里选「自动选择」或「Codex」（只有显示“可自动执行”的 Agent 才会出现在列表里）；
4. 决定要不要勾 **「结果作为新节点」**：
   - 勾上 = AI 结果变成画布上一张新卡片（新手推荐，原文件一点不动）；
   - 不勾 = 在选中卡片的基础上改，生成草稿，原版本也不丢；
5. 按 **Ctrl/Cmd + Enter**（或点 ↑ 箭头）发送；
6. 右边 AI 工作栏会依次显示：排队 → 运行中 → 待确认 → 结果。

## 7. 第四步：结果出来怎么办

AI 干完活，右侧会出现结果确认区，四个按钮：

- **使用这个版本**：接受，结果正式生效；
- **补充修改要求**：不满意，继续提要求；
- **重新执行**：换个说法再跑一次；
- **放弃这个结果**：不要了，一切保持不变。

记住一条底线：**AI 不会偷偷覆盖你的原文件**，所有结果都要经过你确认。

## 8. 第五步（进阶）：实时上下文视图

想看「画布 = AI 的上下文」实时同步，在浏览器地址栏打开：

```text
http://127.0.0.1:5173/?agent=codex&project=disposable-mvp-sample
```

右边会出现 Agent 上下文面板：你单击哪个卡片、当前版本号 vN、参考了哪些内容，全部实时变化。
这就是「不用把画布发来发去，AI 直接看到你正在看什么」。

## 9. 常见问题

**Q：窗口没自动开 / 页面打不开？**
A：先 `npm run dev:status` 看三个端口；哪个没 LISTEN 就重新 `npm run dev:open`。

**Q：输入框显示「暂无可用 Agent」，发送按钮是灰的？**
A：说明当前没有可自动执行的本地 Agent。Codex 自动接单需要：本地起看门狗 + 一个 Codex CLI 会话
（工具在 `tools/codex-orchestrator/watch.ps1`）。没有 Agent 时，先把画布、导入、上下文这些玩熟。

**Q：任务一直「排队」不动？**
A：Agent 没接单。可以先点「撤回任务」，别一直挂着。

**Q：单击卡片没反应？**
A：单击 = 选中 + 弹输入框；双击 = 打开内容。两个动作别搞混。

**Q：浏览器控制台偶尔报 409？**
A：正常。这是两个操作同时修改上下文时的冲突保护，界面会自动刷新恢复。

**Q：我的文件会被改坏吗？**
A：不会。AI 结果默认是新草稿 / 新节点，接受前原文件不动；导入的文件也不会被移动。

## 10. 快捷键小抄

- `C`：聚焦全局输入框
- `Ctrl/Cmd + Enter`：发送命令
- 单击：选中；双击：打开内容
- `Ctrl/Cmd/Shift + 单击`：多选
- `Delete` / `Backspace`：删除选中的卡片（不删原始文件）
- `Esc`：关掉当前弹层
