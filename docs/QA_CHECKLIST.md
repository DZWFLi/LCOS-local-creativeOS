# QA Checklist

## Always

- [ ] Development server opens.
- [ ] `npm run lint` passes.
- [ ] `npm run build` passes.
- [ ] Browser console has no red errors.
- [ ] No unapproved dependencies, backend, API keys, or fake integrations.

## Core demo

- [ ] Two assets switch independently.
- [ ] Human evaluation persists after refresh.
- [ ] Mock AI evaluation completes without network requests.
- [ ] Agreement, attention, and conflict update from the same source data.
- [ ] Markdown downloads and JSON parses.
- [ ] Codex handoff contains required context.
- [ ] 1366×768 has no blocked primary content.
- [ ] 1024px has no horizontal overflow.
