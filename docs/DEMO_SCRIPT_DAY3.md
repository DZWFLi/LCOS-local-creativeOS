# AdFrame Script Review｜Day 3 演示脚本

**建议时长：2 分 45 秒（可压缩至 2 分 30 秒，最长不超过 3 分钟）**  
**固定起点：Script V2 / PRODUCT SETUP / 人工判断**  
**演示案例：PortaSplit / The Thinker**

## 演示前准备

1. 用 Chrome 或 Edge 打开 Demo，推荐窗口为 1366×768。
2. 点击右上角「恢复演示数据」→「确认恢复」。
3. 确认左侧选中 **Script V2**，中间选中 **6–9s · PRODUCT SETUP**，右侧停留在 **人工判断**。
4. 不提前打开 Compare、Brief 详情或底部 Export 抽屉。
5. 演示前不要随意修改预置文本；本脚本按固定 seed 编排。

---

## 0:00–0:20｜一句话建立产品定位

**点击动作**  
不点击，鼠标停在页面顶部项目名附近。

**屏幕展示**  
完整三栏工作台：左侧脚本版本，中间脚本段落，右侧评审面板；当前为 Script V2 / PRODUCT SETUP。

**讲解台词**  
“这是 AdFrame Script Review，一个商业视频脚本 AI 协同评审台。它不替代 GPT 或 Codex 写脚本，而是把 Brief、脚本版本、人工创意判断和 AI Skill 分析放进同一个上下文里，在进入分镜和生成之前，把最便宜、也最关键的问题先解决。”

**失败兜底**  
如果页面没有回到固定起点，立即点击右上角「恢复演示数据」并确认；恢复过程不解释技术细节，只说：“我先回到预设案例起点。”

## 0:20–0:42｜先看 Brief，而不是脱离目标谈审美

**点击动作**  
点击中间顶部 Brief Bar，展开 Creative Direction 与 Locked Elements。

**屏幕展示**  
Objective、Audience、Platform、Format，以及“石膏像角色设定 / 0–6 秒持续拉镜 / 6 秒完整露出产品”等 Locked 条件。

**讲解台词**  
“广告脚本不能脱离 Brief 评价。这个项目要让欧洲租房用户理解 PortaSplit 安装简单、制冷强劲；同时石膏像角色、前六秒持续拉镜和第六秒完整露出产品都已经锁定。系统后面的判断都必须引用这些目标和约束，而不是泛泛地说好不好看。”

**失败兜底**  
如果详情没有展开，直接指向顶部紧凑信息条继续讲 Objective、Audience 和 Platform，不重复点击。

## 0:42–1:05｜脚本版本与具体段落绑定

**点击动作**  
点击左侧 Script V1，再点回 Script V2；重新选择 PRODUCT SETUP。随后点击中间右上角「Source / Current Compare」。

**屏幕展示**  
左侧 V1/V2/V3 版本演进；Compare 区显示来源版本与当前 6–9 秒段落的文本对照。

**讲解台词**  
“这里管理的不是一份孤立文档，而是一次真实的修改链。V1 用冰块表现炎热，客户认为道具来源突兀；V2 改成角色自身动作。现在评审定位到 6 到 9 秒的安装段，并且保留它从哪个版本演变而来、为什么改。”

**失败兜底**  
如果 Compare 没有基线内容，不停留排查，关闭 Compare，改说：“左侧版本和当前段落已经完成绑定，每条意见都会跟随具体版本，而不是漂在项目外面。”

## 1:05–1:32｜展示广告人的 Review Card

**点击动作**  
必要时关闭 Compare；右侧保持「人工判断」。指向预置 Review Card，点击状态按钮一次，将 **open** 推进为 **accepted**；保持 Decision 为 **modify**。

**屏幕展示**  
Review Card 中的 Issue、Impact、Evidence、Suggestion：连续安装动作让“三步自安装”仍然显得复杂；商业影响是用户看见安装教学，而不是“自己也能装”。

**讲解台词**  
“人工评审不是给一个虚假的 82 分，而是形成可执行的判断：问题是什么、影响哪一个商业目标、证据在哪、下一步怎么改。这里的问题不是画面不好看，而是搬运、落地、理管和关门挤在一个段落里，让‘三步自安装’看起来仍然复杂。团队接受这个问题，并决定修改。”

**失败兜底**  
如果误点成其他状态，继续点击直到 accepted；如果卡片没有出现，确认仍是 Script V2 / PRODUCT SETUP，仍无卡片则点击「恢复演示数据」。

## 1:32–1:58｜AI 给初稿，人做商业判断

**点击动作**  
点击右侧「AI 分析」Tab。展示 Product Communication 与 Platform Fit 两条 Mock Skill 发现；在 Human Revision 中输入或粘贴：  
`不要把安装步骤压缩成教学过程；拆成三个广告切镜，每镜只保留一个可读动作。`  
点击「Revise」。

**屏幕展示**  
AI Original、Human Revision、Confidence 与 disposition 从 pending 变为 revised。

**讲解台词**  
“AI 先用固定 Skill 给出分析初稿：动作数量超出信息承载，短视频节奏也不够清晰。但 AI 不是终审。人工把它修订成更符合广告表达的决策——不是单纯减少动作，而是拆成三个广告切镜，每个镜头只传达一个信息点。原始判断和人工修订都会保留。”

**失败兜底**  
如果输入或 Revise 没有即时显示，不刷新页面，直接指向 AI Original 解释人机分工；可说：“这里演示的是处置机制，录屏版会保留修订结果。”

## 1:58–2:20｜把零散意见收束成 Decision

**点击动作**  
点击「Decision」Tab。在“下一版目标”中保留预置内容，或补充：  
`将安装段拆成三步广告切镜，并保持室内外机关系真实。`

**屏幕展示**  
Keep / Modify / Remove 和下一版目标。Modify 中出现已接受 Review 的修改建议。

**讲解台词**  
“评审的终点不是评论越来越多，而是形成版本级 Decision。什么必须保留、什么需要修改、什么应该删除，以及下一版目标，都被统一收束。这样 GPT、Codex 或制作商拿到的是明确任务，不需要重新翻聊天记录猜客户到底要什么。”

**失败兜底**  
如果 Modify 没有同步，直接解释预置 Decision 中的 Keep、Modify、Remove，不现场修数据；避免让演示陷入状态排查。

## 2:20–2:42｜导出可继续工作的上下文

**点击动作**  
点击页面底部「Context / Export」展开抽屉。依次指向 Markdown Review、JSON、Codex Handoff；优先点击 Markdown Review，最后点击 Codex Handoff。

**屏幕展示**  
三个交付出口：面向人阅读的 Markdown、结构化 JSON、可交给 Codex 的 commercial_script_revision 任务上下文。

**讲解台词**  
“最后，系统把 Brief、当前版本、人工评审、AI 草稿、修改决策和下一版目标重新组装。Markdown 可以给客户或团队复核，JSON 可以接后续系统，Codex Handoff 则把它变成下一轮脚本修改任务。AdFrame 管理上下文和决策，真正的创作与执行仍然交给 GPT、Codex 或其他工具。”

**失败兜底**  
- 如果浏览器拦截下载：不重复点击，指向按钮说明“浏览器录屏环境可能拦截下载，导出内容已由同一 builder 生成”。
- 如果剪贴板提示 Copy Failed：立即说“当前浏览器拒绝剪贴板权限，但任务包生成不受影响”，然后指向 JSON 出口收尾。

## 2:42–2:55｜一句话收束价值

**点击动作**  
不再点击，保持 Export 抽屉展开或回到完整工作台。

**屏幕展示**  
脚本版本、结构化评审和导出入口同时可见。

**讲解台词**  
“这个 V0 先从脚本开始，因为脚本是商业目标、创意判断和后续生成上下文的源头。它解决的不是多生成一版，而是让每一版为什么改、改什么、保留什么，都可以追溯并继续执行。”

---

## 2 分 30 秒压缩方案

如果现场时间不足：

- 省略 V1/V2 来回切换，只打开一次 Source / Current Compare。
- Brief 环节压缩为一句：“所有评审都基于目标、受众和 Locked 条件。”
- AI Human Revision 不现场输入，直接展示预置草稿并点击 Revise。
- 导出只讲 Codex Handoff，Markdown 和 JSON 用一句带过。

## 演示纪律

- 不介绍 schemaVersion、localStorage、Repository 或组件结构；这些属于技术追问，不属于三分钟主叙事。
- 不承诺真实 AI API、第二案例、视频评测或 Shot 编辑已经完成。
- 不把 Mock AI 描述成真实模型调用；统一称为“固定 Skill 的模拟输出”。
- 不现场新建复杂 Review；预置 Review 足以展示产品逻辑。
- 遇到失败最多处理一次，随后使用对应兜底台词继续讲价值，不在面试现场修产品。
