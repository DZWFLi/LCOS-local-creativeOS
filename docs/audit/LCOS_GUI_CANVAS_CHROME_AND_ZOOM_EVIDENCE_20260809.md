## 定位内容回归修正

- 复现：定位按钮确实触发，但全量包围盒被远处孤立节点拉大，相机适配到约 5%，主内容仍呈小点，用户感知为“没反应”。
- 修正：定位当前画布最密集的有效内容区，并使用阅读缩放下限；小地图仍保留远处孤岛信息。
- 真实复测：从主内容不在视口的相机状态点击“定位内容”，相机更新后 5 个主内容节点以 58% 可读尺寸回到视口；页面 warning / error 为 0。
