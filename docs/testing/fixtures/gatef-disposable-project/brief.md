# 可丢弃测试项目：Brief

这是一个给开发方做真实 Codex 闭环验证用的临时项目。

## 目标

1. 验证 GUI/API 创建 analyze / revise / create Run；
2. 验证 Codex 自动接单、认领、执行、回传；
3. 验证 cancel、restart、session invalidation、连续 5 Run；
4. 全部结论只写回本目录，不碰任何真实项目。

## 内容

- brief.md（本文件）
- reference-1.png、reference-2.png（两张测试图片）
- sample-skill.yaml（一个 Skill 样本文本）
- notes.json（JSON 样本文本）

## 使用后

整个目录可以直接删除。
