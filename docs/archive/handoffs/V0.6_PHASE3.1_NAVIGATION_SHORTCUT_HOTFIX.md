# v0.6 Phase 3.1 · Navigation & Shortcut Hotfix

## 目标

修复 Phase 3 真实 Chrome 报告中的四个断点，不扩展产品能力：

- Child Scope 返回父 Canvas；
- Composer 的 `C` 与 `Ctrl/Cmd+Enter`；
- 正常创建 Child 的内部关系继承证据；
- Project Tab 关闭入口。

## 关键实现

### Scope Navigation

- `.v06-breadcrumbs` 恢复 `pointer-events: auto`；
- 面包屑改为 `nav`，当前 Scope 使用 `aria-current="page"`；
- 返回父级前保存当前 Scope 与 Workspace Camera；
- 进入目标 Scope 时优先切换到该 Scope 的 Workspace；
- 清空当前选择与 Layout Preview，但不修改 Project Graph。

### Composer Shortcuts

- Composer 内部 `Ctrl/Cmd+Enter` 继续调用 `requestRun()`；
- Window 级增加同一快捷键兜底，解决 BODY 焦点路径；
- 仍只打开 Run Confirm，最终确认前不创建 Process；
- `C` 使用 microtask + requestAnimationFrame 多次尝试，保证 Rail 展开后输入框实际获得焦点。

### Child Relations

- 正常创建路径改成一次确定性的 Graph Transaction；
- 仅复制选中对象之间原有关系；
- `proposal + feedback + reference` 应产生 3 个 View 和 2 条关系；
- Canvas 增加 `data-node-count`、`data-edge-count`、`data-edge-id/from/to` 用于浏览器验收。

### Project Tabs

- Tab 主体与关闭按钮拆分；
- 关闭按钮具有明确 aria-label；
- 单关、活动 Tab 关闭、全部关闭回 Drive 都沿用现有项目会话逻辑。
