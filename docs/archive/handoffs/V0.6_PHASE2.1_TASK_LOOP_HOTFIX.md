# V0.6 Phase 2.1 · Task Loop Hotfix

## 冻结目标

修复浏览器验收暴露的主闭环缺陷，不扩展 Phase 3。

## 关键合同

### 发送合同

```text
Composer 点击发送 / Ctrl/Cmd+Enter
→ requestRun()
→ 下一动画帧打开 RunConfirmDialog
→ Canvas 锁定
→ 用户点击开始执行或在已稳定打开的 Dialog 内再次 Ctrl/Cmd+Enter
→ 创建 Command / Context Snapshot / Run / Process Node
```

首次 Ctrl/Cmd+Enter 不得在同一按键事件中创建 Process。

### 聚焦合同

```text
C / 顶部告诉 AI / Compact Composer / Continue Modify
→ requestComposerFocus()
→ 展开 Work Rail
→ React 提交完成
→ 双 RAF 后聚焦 textarea
→ 光标移动到文本末尾
```

禁止再次使用固定毫秒数猜测 DOM 何时存在。

### Accept 合同

Accept 在同一个 Graph Transaction 内完成：

- Pending Artifact → Working Current；
- 原 Target → Archived；
- Current-following Views → 新 Revision；
- Process Node → Completed Compact；
- 活动关系 → Static；
- 再更新 ActiveRun 与 Checkpoint UI。

## 不变范围

- Phase 1.1 Canvas 完整锁定；
- Target / Context 推断；
- Waiting Input；
- Artifact Return / Review；
- Continue Modify 将 Draft 设为下一 Target；
- 单一 Work Rail。
