# v0.6 Phase 3 开发交接

## 1. 正式空间模型

```text
Local Creative OS
└── Project Drive
    └── Project Package
        └── Project Graph
            ├── Root Canvas Scope
            ├── Child Canvas Scope
            ├── Workspace Semantic Viewport
            └── ArtifactView
```

一个 Project 只有一个 Graph。Root / Child Canvas 只是 Scope，不复制业务真相。

## 2. 本轮实现

### Project Drive

- `ProjectDrive.tsx` 提供搜索、本地项目、待确认结果和空白项目入口；
- Project Tab 支持多项目打开、切换和关闭；
- `resetGraph()` 切换项目时重置 Undo / Redo 历史，避免跨项目串线；
- PortaSplit 与华新项目使用不同 Fixture Graph，浏览器可以确认切换不是换标题演戏；
- 项目状态按 `projectId` 存储。

### Child Canvas Scope

- 多选工具条新增“子画布”；
- `ScopeCreateDialog` 只询问名称与用途；
- 创建后生成：Container Node、CanvasScope、ArtifactViews、内部关系；
- 原节点留在父画布，不移动真实文件；
- Child View 继承 `artifactId`、Revision 跟随状态和可编辑属性；
- 容器节点双击进入 Scope；
- Breadcrumb 返回任意父 Scope；创建并进入 Child Scope 前会保存父 Scope Camera，返回后恢复原现场。

### 自动布局

- `proposeScopeLayout()` 只处理当前 Scope；
- `positionLocked` 对象不会进入布局预览；
- 未固定节点围绕固定对象寻找空位；
- Apply 后保存 `layoutMode: semantic` 并 Fit 当前 Scope；
- Work Rail 可切换“固定位置 / 允许自动排列”。

### 删除合同

删除 Container View 时同时删除其 Scope Tree 与 Scope 内的 Views / Edges，但不会删除父 Scope 中引用的 Artifact。指向已删除 Scope 的 Workspace 会回退到当前父 Scope。

## 4. 后端接入边界

当前仍为 Fixture Frontend。后端接入时替换：

- Project Catalog / Local Directory；
- Project Graph Query；
- Scope / ArtifactView Persistence；
- File Watcher；
- Run Runtime；
- Artifact Return 与 Revision；
- Checkpoint / Delivery。

不可改变黄金路径和空间语义。
