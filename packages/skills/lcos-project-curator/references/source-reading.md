# 来源读取边界

## 原则

Skill 只处理用户明确指定的来源。默认读取范围：

```text
用户指定的对话轮次 / @ 文件 / 网页 / 当前 Selection
+ lcos search 的必要命中（用于去重与关联）
```

## 禁止默认读取

```text
全部聊天历史
整个磁盘
整个项目所有节点
未提及的目录
```

## 实际操作

1. 用户说“今天这三轮”→ 只读这三轮，必要时读命中相关性的既有节点。
2. 用户 @ 了网页/文件 → Agent 当前能看到就纳入。
3. 当前 Selection → 用 `lcos selection read <project>` 只读选中内容。
4. 不确定范围 → 先问一句，不猜。

## 边界信号

```text
“整个项目都整理一下” ≠ “把项目所有文件都建节点”
“看看这个文件夹” ≠ “递归导入所有文件”
```

模糊指令先缩小到可验证范围，再执行。
