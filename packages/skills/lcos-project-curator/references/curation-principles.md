# 策展原则

## 四选一

每个候选内容必须明确归类：

```text
create  —— 独立阅读价值 + 未来可能被引用 + 与现有内容不重复
update  —— 明显同一主题的持续沉淀，且不覆盖用户手写重要文本
reuse   —— 已有节点已表达该内容，只加关系/引用
skip    —— 噪音、临时、重复、无独立价值
```

## 摘要粒度

- 每个 GUI Text Node 独立可读（不依赖其它节点才能懂）
- 少量高信息密度
- 避免同义重复（一个意思只出现一次）
- 避免一句话一个节点
- 避免整场对话一个超级节点

## 反模式

```text
“第 1 点、第 2 点…” 固定模板
把每条消息单独建节点
把整段对话原样粘贴
```

## 覆盖安全

```text
来源不确定 → 新建 + Relation（宁可多一个节点）
用户手写的重要文本 → 不动，除非用户明确要求改写
```
