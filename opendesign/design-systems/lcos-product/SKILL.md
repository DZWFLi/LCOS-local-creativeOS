# LCOS Product Interface

Use this system for the LCOS App Shell, Canvas objects, Workspace views, Workbench, Run surfaces and local overlays.

## Non-negotiable product hierarchy

1. Content or preview.
2. Object shape and identity.
3. Current selection and action target.
4. Pending, exceptional or running state.
5. Category accent.
6. Workspace atmosphere.
7. Rare iridescent active detail.

Do not turn LCOS into a generic white-card SaaS dashboard. Keep the Canvas quiet and spatial; use porcelain and cool-neutral surfaces for chrome. Category color is a fine signal, never a full-height stripe or a large filled panel.

## Interaction language

- Controls use explicit hover, pressed and focus-visible feedback.
- The interface exposes one primary action per local row.
- Motion is restrained, normally 140–220ms, and fully reduced under `prefers-reduced-motion`.
- Technical IDs, raw paths and provider details belong in Inspector or diagnostics, not the primary Canvas.
