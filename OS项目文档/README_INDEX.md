# Local Creative OS 文档总索引

本文件用于统一管理当前项目阶段的 Markdown 文档。

## 01 当前核心文档

1. `Local_Creative_OS_Project_Brief.md`  
   项目总纲，包含定位、架构、产品边界、视觉方向和推进路线。

2. `CODEX_Local_Project_Reorganization_Handoff.md`

4. `Local_Creative_OS_UI_Spec_v0.1_PM_Review.md`  
   对前端视觉与交互规范 v0.1 的开发 PM 评审。

5. `Local_Creative_OS_UI_Information_Density_Addendum.md`  
   Sub-canvas、旧 Run、Workspace 折叠、辅助文件 Stack 和 Checkpoint 历史收拢决策。

6. `Local_Creative_OS_Pre_Development_Readiness_Plan.md`  
   正式开发前准备工作、技术 Spike、数据合同、样例项目和验收脚本。

7. `Local_Creative_OS_Storage_Cache_Performance_Budget.md`  
   存储、缓存、运行压力、SQLite、Canvas 性能和容量预算。

8. `Local_Creative_OS_GUI_Project_Coordination_ADR.md`  
   Local Creative OS 与 Codex / WorkBuddy GUI 的项目分类、Run 映射和文件冲突规范。
